# 12. Final Evaluation — Guarded Stage

This stage is intentionally not executable yet.

The final-test snapshot is **2013-10-01**. Its labels must remain untouched until:

1. feature set is frozen;
2. model architecture is frozen;
3. imbalance strategy is frozen;
4. hyperparameters are frozen;
5. threshold strategy is frozen.

Only after those choices are fixed should a final-evaluation script be added here.

This empty guarded stage is deliberate. It prevents an exploratory script from
accidentally turning the final test into additional development data.
